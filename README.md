# TAPATCH packages

Package-manager manifests for the free Windows tools from [TAPATCH](https://tapatch.com).
Free for personal use. Business or commercial use requires a paid license (see https://tapatch.com/terms/software/).

## Scoop

```powershell
scoop bucket add tapatch https://github.com/tapatchUSA/packages
scoop install tapatch/linkmass
```

## Chocolatey

```powershell
choco install linkmass
```

The Chocolatey package sources live in [`chocolatey/`](chocolatey/).
